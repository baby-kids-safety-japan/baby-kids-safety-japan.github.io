# 赤ちゃんとこどもの安全ノート

日本の赤ちゃんとこどもの事故予防を、月齢・年齢別にまとめた保護者向けのサイト。

**<https://baby-kids-safety-japan.github.io/>**

## 何のためのサイトか

子どもの事故を防ぐ情報は、公的機関のページに散らばっていて、必要な時期に必要なものを
見つけにくい。このサイトは、それを**月齢・年齢のタブ**に並べ替えて、
その時期に気をつけることが一度に見渡せるようにしたもの。

- **網羅性** ── 0〜3か月から10歳〜までの7タブ、96項目。
- **根拠をたどれること** ── 全項目に「この項目の根拠」があり、
  こども家庭庁・消費者庁・警察庁・国土交通省・環境省・気象庁・海上保安庁・
  日本小児科学会などの該当ページに直接リンクする。
  どの記述がどの資料のどの記載に対応するかも書いている。
- **図解** ── 手順と、やってはいけない例・よい例を、イラストで示す。
- **グッズ** ── 各項目に、その項目の安全上の根拠から導いた選び方と、商品を3つ以上。
  商品で解けない項目には置かない。

掲載内容は一般的な情報であり、個別の診断や指導に代わるものではない。

## 動かす

```
python3 src/build.py          # index.html / sitemap.xml / robots.txt を生成する
python3 src/link_check.py     # 出典のリンク切れを調べる
python3 -m http.server 8123   # http://localhost:8123/
```

`index.html` は生成物。本文を直すときは `src/content.py` を編集して再ビルドする。

```
src/content.py      本文データ（タブ→グループ→項目）
src/sources.py      出典レジストリ
src/products.py     商品レジストリ
src/glossary.py     用語のツールチップ
src/build.py        ビルドとバリデーション
src/link_check.py   出典のリンクチェック
src/install_image.sh 図解イラストの設置
assets/             スタイル、スクリプト、図解イラスト
```

## ビルドが止める間違い

`src/build.py` の `validate()` が次を検査し、違反があればビルドを中止する。
量産中に踏みやすい間違いを機械で止めるためのもの。

- 出典・商品の未登録キー、図の画像ファイルの不在、図の種類の誤り
- レジストリの重複キー、**同じURLを指す出典キーの重複**
- `content.py` の項目 dict の重複キー、**描画されない未知のキー**
- グッズ枠の商品が3件未満、サブタイトルや根拠の欠落

## 制作上の決まりごと

項目の追加手順、出典の集め方、商品の選定方針、アフィリエイトの規約上の制約、
図解イラストの作り方は、Claude Code の `baby` スキルに記録してある。

ここだけは README にも書いておく。

- **根拠のない記述を足さない。** 一次情報を確認してから書き、`src/sources.py` に登録する。
  リンク集やポータルを出典にしない。資料が宣言している対象年齢の外で使わない。
- **価格・在庫・★評価・商品画像を出力しない。** Amazonアソシエイト運営規約により、
  PA-API 経由で取得したもの以外は掲載できない。
- **広告であることの表示を外さない。** 各グッズ枠の `PR` バッジと、フッターのアソシエイト表記。
- **リンクが生きていることと、中身が変わっていないことは別。**
  数値・年月日・法令名を書いた項目は、原典を開き直して確かめる。
