離れるとき

目を離すときは、置き場所を決めてから#

離れないのは無理。先に「どこに置くか」を決めておく

インターホン、トイレ、上の子の呼び声、火にかけた鍋。赤ちゃんから離れる場面は一日に何度もあり、なくすことはできません。決めておくのは「離れないこと」ではなく、離れる前に赤ちゃんをどこに置くかです。

  1. 安全な置き場所を2か所決めておく

    柵をいちばん上まで上げたベビーベッドと、床に敷いたプレイマット。この2つなら、とっさのときに迷いません。

  2. あおむけで、まわりに何も置かずに寝かせる

    ぬいぐるみ、クッション、タオル、スタイ、ひも状のものを残しません。

  3. 離れる前に、見える範囲を一度だけ確認する

    手の届く所に小さなもの、コード、熱いものがないか。数秒で済みます。

  4. 戻る時間の見当をつけてから離れる

    長くなりそうなら、連れて行くほうが早いこともあります。

  • ×しないこと：
    ソファ・大人用ベッド・おむつ替え台に置いたまま離れない
    寝返り前でも落ちます。すき間に挟まる、柔らかい面に顔が埋もれるという危険も重なります。
  • ×しないこと：
    バウンサーやベビーチェアに座らせたまま離れない
    ベルトをしていても、体がずり落ちてベルトで首が圧迫されることがあります。バウンサーは軽いので、赤ちゃんが動くと本体ごと動きます。眠ってしまったときは、傾いた姿勢であごが胸に埋まって気道がふさがります。
  • ◯すること：
    沐浴・入浴中は、どんなに短くても連れて出る
    「すぐ戻るから」がいちばん危険です。わずかな水深でも溺れます。
  • ×しないこと：
    上の子やペットと二人きりにしない
    子ども同士の見守りは対策になりません。0歳では、犬による咬傷と、ウサギの咬傷が疑われた指の欠損が報告されています。どうしても離れる場面では、赤ちゃんを柵のあるベビーベッドに下ろし、上の子とペットを別の部屋に出してドアを閉めてから離れます。上の子には「見ていて」ではなく「赤ちゃんのいる部屋に入らないで」と頼みます。
  • ◯すること：
    泣きやまなくて限界のときは、安全な場所に寝かせて離れてよい
    柵付きのベビーベッドなどにあおむけに寝かせ、部屋を出て、ひとりで泣かせておきます。5〜10分ごとに呼吸を確認します。これは公的な資料ですすめられている対処です。
